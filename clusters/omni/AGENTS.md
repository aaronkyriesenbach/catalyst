# OMNI CLUSTER KNOWLEDGE BASE

A standalone Talos cluster that runs Omni, which manages every other cluster. It is built with Pulumi, not rendered by the catalyst CMP: there is no `apps/` directory and no Argo. Framework conventions live in the repo-root `AGENTS.md`; the runbook is `infra/README.md`. Paths here are relative to `clusters/omni/`.

### Independence

Omni must not run on a cluster it manages, and it is the root of trust, so nothing depends on cluster0: images come from upstream registries (every `versions.ts` entry used here has `mirrored: false`), and there is no zot, Traefik or external-secrets dependency.

### Addressing

All addresses come from `site.ts`: VLAN `site.omni.vlan` (`10.53.<vlan>.0/24`), the API VIP in the `vip` block, nodes in the `host` block, the Gateway and WireGuard addresses in the `loadBalancer` block. `infra/common.ts` reads them through `ipOf` and `allocationsOf`, so referencing an address the plan does not allocate fails `bun run typecheck`. Hostnames are `*.int.lab53.net`: `omni`, `omni-k8s`, `omni-siderolink` and `dex`.

### Cluster

Three combined control-plane and worker Talos nodes, one per PVE node, 4 vCPU, 8 GiB, 60 GiB on `local-lvm`. Talos config (`packages/infra/talos-patches.ts`, `infra/cluster/firewall.ts`):

- Flannel and kube-proxy are off; Cilium replaces both (Talos guide values in `infra/cluster/cilium.ts`).
- The Talos ingress firewall blocks by default and lists each allowed source; the admin address is `site.network.adminNetworks`.
- Pod Security defaults to `restricted`; only `kube-system` is exempt. `omni` is the one `privileged` namespace (it needs `NET_ADMIN` for WireGuard).
- Disks are not encrypted: there is no vTPM and no secure boot.

### Networking

Cilium is the CNI, kube-proxy replacement, node-to-node WireGuard encryption, the load-balancer (`CiliumLoadBalancerIPPool` and L2 announcements in `infra/platform/load-balancer.ts`) and the Gateway API controller. Every namespace comes from `lockedDownNamespace` in `packages/infra/namespace.ts`: a Pod Security label and a default-deny `NetworkPolicy`. Allows are `CiliumNetworkPolicy` objects (`infra/policies.ts`), because traffic from the Gateway carries Cilium's `ingress` identity, which a standard policy cannot select.

### Identity and secrets

Login is Dex with one static user (`aaron@lab53.net`); the password and the OIDC client secret are generated by Pulumi. The etcd encryption key is generated once by `infra/platform/generate-etcd-key.sh` and stored as a Pulumi secret and in AWS (`lab53/omni/omni/...`, built with `awsSecretKey`).

### Backups

A CronJob (`omni-etcd-backup`, every 6 hours) runs `etcdctl snapshot save` against Omni's embedded etcd over mTLS and uploads it to a versioned, encrypted S3 bucket with 30-day expiry. Omni's own `etcdBackup` setting backs up managed clusters, not Omni, so it is not used. VMs are also backed up by the `omni-vms` PVE job.

### Open decision

The storage driver is not chosen. Omni stays disabled (`omniEnabled: "false"`) until `storageClass` is set.
